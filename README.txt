# Dağ Oto Ford Trucks - Ücretsiz Site

Bu klasör GitHub Pages gibi ücretsiz statik hostinglerde yayınlanabilir.

## Yayına almadan önce
1. `script.js` içindeki `WHATSAPP_NUMBER` değerini işletme WhatsApp numaranızla değiştirin.
2. `index.html` içindeki telefon ve adres bilgilerini gerçek bilgilerinizle değiştirin.
3. İsterseniz `map-placeholder` alanını Google Maps iframe koduyla değiştirin.
4. Kendi servis/araç fotoğraflarınızı `assets` klasörüne ekleyip hero veya galeri bölümüne bağlayabilirsiniz.

## Önemli
Bu sürümde randevu formu doğrudan WhatsApp mesajı oluşturur; sunucu/veritabanı gerektirmez.
